# 标注规范（精度评测用）

`precision_eval.py` 的输入是**人工标注真值**。本规范定义标注什么、怎么存、怎么跑评测。

## 标注什么

每张图（或每帧）标 **5 个锚点**的像素坐标——与 `metrics.py` 参与坐姿指标计算的关键点一致：

| 名称（JSON key） | 含义 | MediaPipe 33 点下标 |
|---|---|---|
| `nose` | 鼻尖 | 0 |
| `left_ear` | 左耳屏 | 7 |
| `right_ear` | 右耳屏 | 8 |
| `left_shoulder` | 左肩峰 | 11 |
| `right_shoulder` | 右肩峰 | 12 |

坐标系与代码一致：**图像像素系，原点左上，x 向右，y 向下**（不是数学坐标系）。

## JSON 格式

```json
{
  "version": 1,
  "coord": "pixel, y down",
  "samples": [
    {
      "id": "frame_0001",
      "keypoints": {
        "nose": [320.5, 180.2],
        "left_ear": [281.0, 175.0],
        "right_ear": [360.8, 176.5],
        "left_shoulder": [270.1, 300.4],
        "right_shoulder": [371.2, 302.0]
      }
    }
  ]
}
```

- `id`：样本编号。用 `--images` 走检测器时按 `{id}.jpg` 找图
- 预测值三种来源，优先级从高到低：
  1. 样本内 `"pred": {同 keypoints 结构}`
  2. `--pred` 独立预测文件（同结构，按 `id` 配对）
  3. `--images` 目录 + MediaPipe 现场推理（依赖装好才可用）

## 怎么标

- 工具随意：labelme / CVAT / 自写脚本 / 看图手填，只要导出成上面的 JSON
- 每张图大约 1–2 分钟；关键点按**解剖位置**标（鼻尖、耳屏、肩峰），不按软件检测框
- 检测器没检出、你自己也看不清的点 → **弃掉这张图**，不要猜坐标（猜出来的真值是假真值）

## 样本量与覆盖

- **起步 50–100 帧**：好姿势 / 低头 / 驼背 / 左右偏都要有，正面与带角度的视角都来一些
- 同一个人不同衣服、不同坐姿的帧优于同一姿势截 100 张
- 样本量 < 30 时报告里的汇总统计只作个案参考（报告自带此提示）

## 跑评测

```bash
# 预测已存在（pred 文件或样本内 pred）
python precision_eval.py --ann data/annotations.json --pred data/predictions.json

# 现场用 MediaPipe 出预测（需装 mediapipe + opencv）
python precision_eval.py --ann data/annotations.json --images data/frames/

# 只看流程（合成演示对，报告标"演示"）
python precision_eval.py --demo
```

输出报告含两块：**PCK@0.1**（误差 ≤ 肩宽 10% 的关键点命中率）与 **θ/d/s 任务指标误差**（MAE/RMSE/P95）。

## 口径（答辩可直接引用）

- PCK 回答"点标得准不准"（定位精度），阈值按肩宽归一化，不依赖图片分辨率
- θ/d/s 误差回答"算出的坐姿指标偏多少"——这是真正流进分级阈值的量
- 与 benchmark 的"角度一致性"互补：一致性是**稳定性**，本规范是**精度**，两者不混用
