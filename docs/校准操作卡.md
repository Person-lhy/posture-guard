# 校准操作卡

阈值校准的两套流程：**A 合成演示**（零依赖，验证链路 / 答辩演示用）和 **B 真数据校准**（自用，跑一天后出个人阈值）。

原理：warn ≈ 不良姿势分布 P15，recover ≈ 正常姿势分布 P85。两分布重叠无区分度时**拒绝给建议**——给没有区分度的阈值等于装了误报制造器。

---

## A. 合成数据演示（现在就能跑，纯 stdlib）

```bash
cd posture-guard

# 1) 生成 4 类合成会话 CSV + 摘要 → data/demo/
python make_demo_data.py

# 2) 对每类会话算建议阈值
python -c "
import storage, autotune
storage.DATA_DIR = 'data/demo'
for day in ['20260101_slouch', '20260101_drop', '20260101_side', '20260101_mixed']:
    s = autotune.suggest_from_day(day)
    print(day); print(autotune.describe(s)); print()
"
```

预期结果（合成数据干净，数字仅供看流程）：

| 会话 | 演示点 | 预期输出 |
|---|---|---|
| slouch | 只有颈角变差 | 仅颈角 warn/recover 一对建议 |
| drop | 只有低头变差 | 仅低头 warn/recover 一对建议 |
| side | 颈角 + 肩歪 | 两对建议 |
| mixed | 混合稀释 | **"无区分度，没有可自动校准的阈值"** |

## B. 真数据校准（装好依赖后）

### 1. 准备

```bash
venv\Scripts\pip install -r requirements.txt   # 首次；已装可跳过
python app.py                                  # 驻留系统托盘，正常用
```

### 2. 收集一天

- 正常坐着工作即可，每秒指标自动落盘 `data/当日.csv`（只存数值与分级，不存图像）
- **好姿势和坏姿势都要有**：正常坐着为主，故意低头 / 驼背 / 偏几分钟。整天只有一种姿势 → 无区分度 → 不出建议（这是设计行为，不是 bug）

### 3. 出建议并写入

```bash
# 方式 1（推荐）：托盘右键 →「自动校准阈值」→ 弹窗展示建议 → 确认写入

# 方式 2：命令行
python -c "import autotune; print(autotune.describe(autotune.suggest_from_day()))"   # 预览
python -c "import autotune; autotune.apply(autotune.suggest_from_day())"             # 写入 settings.json
```

### 4. 生效

**重启 app**（阈值启动时加载）。`settings.save()` 落盘前自动夹紧 recover ≤ warn，手改写反也不会把分级器弄断。

## 常见情况

| 现象 | 原因 | 处理 |
|---|---|---|
| "数据不足或分布无区分度" | 当天姿势太单一 / 两分布重叠 | 明天补坏姿势样本再跑 |
| 只出单侧建议（只有 warn 或只有 recover） | 当天只有坏（或只有好）样本 | 正常现象，另一侧保留旧值 |
| 建议值和默认差很多 | 个人习惯确实偏离起步值 | 以数据为准，写入后观察一两天误报率 |
| 校准后提醒变多/变少 | 阈值变严/变松 | 可回 settings.json 手调，或再收一天重校 |

## 口径（答辩可直接引用）

- warn/recover 用**分布分位数**锚定（不良 P15 / 正常 P85），不是拍脑袋的固定角度
- 分位数由纯 stdlib 计算（不依赖 pandas）；负 θ 取绝对值参与统计，避免正负抵消
- 拒绝建议时如实报告，宁可不校准，不输出无区分度阈值
