## 五、面试高频追问（速答骨架，详见答辩 FAQ）

1. **为什么不用端到端深度学习分类坐姿？**
   标注成本高 + 黑盒不可解释。MediaPipe 本身是 DNN 负责视觉，我的工作在可解释的决策层——阈值可调、判定可审计。
2. **正面摄像头能量低头吗？**
   侧视角度公式会退化（鼻耳同 x，atan2 打到 ±90°），所以低头用比值 d=鼻下移/肩宽，无量纲、正面稳、自带尺度归一。
3. **误报会不会烦死人？**
   六层防护：中值滤波 / 迟滞双线 / 15s 才响 / 300s 冷却 / 静默+上限 / 小睡。原则：宁可漏提醒，不可烦到关软件。
4. **精度多少？**
   无标注真值不宣称精度——测的是输出稳定性（报告口径写明"一致性≠精度"）；阈值从个人数据标定。PCK / 角度误差评测管线已备好（precision_eval.py + 标注规范），标注即出数。
5. **最大的坑？**
   坐标系 y 向下导致 atan2 符号全反；跨模块状态残留（离开工位计时不清零→回来误报）被集成测试抓出——单测测不到这类残留。

**应对原则**：不会就承认，说清思路与下一步；被戳设计缺陷先说"确实"再讲取舍；数字全部对齐 config.py 与本文件，不现场心算。
